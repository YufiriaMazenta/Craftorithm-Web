========================================================
 Craftorithm 配方工作台 · 生产版本
========================================================

这是已经构建好的成品，不含源码，也不需要 Node.js 或 npm。
解压后直接启动即可使用。


------------------------------------------------
 怎么启动
------------------------------------------------

Windows
  双击 start.bat

  它会自动挑选可用的运行方式（有 Python 就用 Python，
  没有就用 Windows 自带的 PowerShell），然后打开浏览器。

macOS / Linux
  在这个文件夹里执行：
      python3 serve.py

浏览器会自动打开 http://127.0.0.1:8080/
如果没有自动打开，手动在浏览器里输入这个地址。

停止服务：在窗口里按 Ctrl+C


------------------------------------------------
 为什么不能直接双击 site/index.html
------------------------------------------------

页面的脚本是 ES module。浏览器对 file:// 协议下的模块脚本
执行 CORS 检查并直接拒绝加载，所以双击打开会是一片空白。
必须通过 HTTP 访问，这也是这个启动器存在的唯一理由。


------------------------------------------------
 常用参数
------------------------------------------------

换端口（8080 被占用时会自动往后找，也可以手动指定）
    python serve.py --port 9000
    powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 9000

不自动打开浏览器
    python serve.py --no-browser

让局域网内其他设备也能访问（仅 Python 版支持）
    python serve.py --host 0.0.0.0

    请注意：这个工具没有登录，也没有任何权限控制。
    用 0.0.0.0 意味着同网段里任何人都能打开并编辑。
    只在可信网络里这样用，不要暴露到公网。


------------------------------------------------
 关于联网
------------------------------------------------

工具本身完全在本地运行，你的配方数据只存在浏览器里，
不会上传到任何地方。

物品贴图与材料标签会从公共 CDN（jsdelivr）拉取。
断网时工具照常可用，只是物品图标会退回显示 ID 文本。


------------------------------------------------
 放到自己的 Web 服务器上
------------------------------------------------

site/ 目录就是完整的静态站点，可以直接交给
nginx、Apache、IIS、GitHub Pages 等托管，不需要这个启动器。

资源引用全部是相对路径，因此放在子目录下也能正常工作，
例如 https://example.com/craftorithm/ 。
